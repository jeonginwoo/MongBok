# 몽복 (MongBok)

**여러 스트리밍 플랫폼을 하나의 화면에서, 당신만의 멀티뷰를 완성하세요.**


## 📖 프로젝트 소개 (Introduction)

**몽복**은 여러 스트리밍 플랫폼의 방송을 하나의 화면에 모아볼 수 있는 강력한 멀티뷰 웹 애플리케이션입니다. 더 이상 여러 개의 브라우저 창을 띄우고 수동으로 배치할 필요 없이, 깔끔하고 편리한 UI를 통해 원하는 방송들을 자유롭게 시청하고 관리할 수 있습니다.

## 🖥️ 지원 플랫폼

- **치지직 (CHZZK)** — 페이지 임베드 없이 전용 HLS 플레이어로 직접 재생하여 가볍고, 실시간 지연이 약 3초로 짧습니다. 재생 실패 시 페이지 임베드 방식으로 자동 전환됩니다.
- **숲 (SOOP, 구 아프리카TV)**
- **유튜브 (YouTube)** — 스트리밍 시간·채팅 데이터는 별도의 [YouTube 채팅 서버](#-youtube-채팅-서버)를 통해 가져옵니다.
- **트위치 (Twitch)** — 채널 검색과 채팅 표시(배지 포함)를 지원합니다.

## ✨ 주요 기능 (Key Features)

- 📺 **멀티 플랫폼 지원**: 치지직, 숲, 유튜브, 트위치 방송을 한 곳에서 시청할 수 있습니다.
- 🔍 **채널 검색 및 관리**:
  - 플랫폼 통합 검색으로 채널을 찾아 클릭 한 번으로 추가할 수 있습니다.
  - 사용하지 않는 플랫폼은 검색 대상에서 토글로 켜고 끌 수 있습니다.
  - 검색으로 찾기 어려운 채널은 설정 > 설정 동기화에서 채널ID로 직접 추가할 수 있습니다.
  - 목록의 채널은 시청자순 → 채널명순으로 자동 정렬됩니다.
- 🎨 **자유로운 레이아웃**:
  - 드래그 앤 드롭으로 방송 화면과 채팅창의 위치를 마음대로 변경할 수 있습니다.
  - 시청 중인 방송 개수에 따라 최적화된 레이아웃을 선택할 수 있습니다.
  - 다양한 화면 비율(16:9, 9:16 등)을 지원하며, 모바일에서는 기기 방향에 따라 자동 전환됩니다.
- 🎛️ **강력한 컨트롤러**:
  - 채널 검색, 추가, 삭제 등 모든 관리를 사이드바 컨트롤러에서 할 수 있습니다.
  - **리모컨**: 컨트롤러(+설정)를 별도 창으로 분리해 리모컨처럼 사용할 수 있습니다.
  - **테마/포인트 컬러**: 라이트/다크 모드와 다양한 포인트 컬러를 지원하여 나만의 UI를 꾸밀 수 있습니다.
  - **설정 프리셋**: 설정 구성(채널 목록, 레이아웃, 레이아웃별 시계 위치 포함)을 1~5번 프리셋으로 저장해두고 버튼 하나로 즉시 전환할 수 있습니다.
  - **설정 동기화**: 즐겨찾는 채널과 설정을 텍스트로 백업하고 복원할 수 있어, 언제 어디서든 내 환경 그대로 시청 가능합니다.
  - **화면 조작**: '화면 조작 모드'를 통해 각 방송 플레이어의 세밀한 제어가 가능합니다.
- ⏺️ **화면 녹화**:
  - 방송 화면(탭 영역)을 고화질/고음질로 녹화할 수 있습니다.
  - **바로 탐색 가능한 파일**: 탐색 인덱스가 포함된 상태로 저장되어, 재인코딩 없이 원하는 위치로 바로 이동할 수 있습니다 (H.264는 MP4, VP9/VP8은 WebM).
  - **자동 녹화**: 1번 구역 채널이 라이브를 시작하면 자동으로 녹화를 시작할 수 있습니다.
  - **녹화 종료 기준**: 전체 채널 오프라인 시 / 1번 채널 오프라인 시 / 수동 종료 중 선택할 수 있습니다.
- ⌨️ **편리한 단축키**: 자주 사용하는 기능들을 단축키로 빠르게 실행할 수 있습니다.
- 🔄 **실시간 정보 갱신**: 배치된 채널은 60초, 목록의 채널은 10분마다 자동 갱신되며, 버튼 하나(또는 `R` 키)로 즉시 새로고침할 수 있습니다.

## 🚀 시작하기 (Getting Started)

1.  **채널 검색**: 우측 컨트롤러 상단의 검색창에서 원하는 스트리머를 검색하세요.
2.  **채널 추가**: 검색 결과에서 채널을 클릭하여 목록에 추가합니다.
3.  **화면 배치**: 목록의 채널을 클릭하거나 원하는 위치로 드래그하여 화면에 배치합니다.
4.  **레이아웃 변경**: 컨트롤러의 비율/레이아웃 버튼으로 화면 구성을 조정합니다.
5.  **시작!**: 이제 당신만의 멀티뷰를 즐기세요!

## ⌨️ 단축키 정보 (Shortcuts)

| Key | 기능 |
| :---: | :--- |
| `1`, `2`, `3`... | 레이아웃 유형 변경 (`0`은 마지막 레이아웃) |
| `C` | 컨트롤러 펴기/접기 |
| `S` | 설정 열기/닫기 |
| `M` | 라이트/다크 모드 전환 |
| `T` | 현재 시간 표시/숨기기 |
| `P` | 현재 시간 표시 위치 변경 |
| `V` | 화면 이동/조작 모드 전환 |
| `R` | 모든 채널 정보 새로고침 |
| `F` | 전체 화면 전환 |
| `↑`, `↓` | 화면 비율 변경 |
| `←`, `→` | 채팅창 글자 크기 조절 |

## 📡 YouTube 채팅 서버

유튜브의 기술적인 구조상 브라우저에서 직접 채팅 데이터를 가져오는 데 한계가 있어, 이를 보조하는 가벼운 서버 프로그램이 별도로 필요합니다. 앱 내 가이드 페이지에서 운영체제(Windows/macOS)에 맞는 파일을 다운로드하여 실행하면 유튜브의 스트리밍 시간, 마지막 방송 시간, 채팅 데이터를 사용할 수 있습니다.

## 📌 참고사항

- **채팅 작성 불가**: 채팅 참여는 각 플랫폼 사이트에서 직접 해야 합니다.
- **광고 및 성인 콘텐츠**: 보안 정책상 로그인이 차단되어, 구독 중이라도 광고가 나올 수 있고 19세 이상 콘텐츠는 시청할 수 없습니다.
- **메모리 사용량**: 4~5개 채널 동시 시청 시 약 2~3GB의 메모리가 사용될 수 있습니다.
- **숲(SOOP)**: 같은 방송을 동시에 두 곳에 띄울 수 없습니다.
- **저작권**: 녹화된 영상의 모든 저작권은 해당 스트리머에게 있습니다. 무단 배포 및 공유를 엄격히 금하며, 반드시 개인 소장용으로만 이용해 주시기 바랍니다.
