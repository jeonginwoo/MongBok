# 스퓨즈 (S-Fuz)

**여러 스트리밍 플랫폼을 하나의 화면에서, 당신만의 멀티뷰를 완성하세요.**


## 📖 프로젝트 소개 (Introduction)

**스퓨즈**는 여러 스트리밍 플랫폼의 방송을 하나의 화면에 모아볼 수 있는 강력한 멀티뷰 웹 애플리케이션입니다. 더 이상 여러 개의 브라우저 창을 띄우고 수동으로 배치할 필요 없이, 깔끔하고 편리한 UI를 통해 원하는 방송들을 자유롭게 시청하고 관리할 수 있습니다.

## ✨ 주요 기능 (Key Features)

- 📺 **멀티 플랫폼 지원**: **치지직(Chzzk)**, **숲(SOOP, 구 아프리카TV)**, **유튜브(YouTube)** 방송을 한 곳에서 시청할 수 있습니다.
- 🎨 **자유로운 레이아웃**:
  - 드래그 앤 드롭으로 방송 화면과 채팅창의 위치를 마음대로 변경할 수 있습니다.
  - 시청 중인 방송 개수에 따라 최적화된 레이아웃을 선택할 수 있습니다.
  - 다양한 화면 비율(16:9, 9:16 등)을 지원하여 어떤 환경에서도 최적의 시청 경험을 제공합니다.
- 🎛️ **강력한 컨트롤러**:
  - 채널 검색, 추가, 삭제 등 모든 관리를 사이드바 컨트롤러에서 할 수 있습니다.
  - **테마/포인트 컬러**: 라이트/다크 모드와 다양한 포인트 컬러를 지원하여 나만의 UI를 꾸밀 수 있습니다.
  - **설정 동기화**: 즐겨찾는 채널과 설정을 텍스트로 백업하고 복원할 수 있어, 언제 어디서든 내 환경 그대로 시청 가능합니다.
  - **화면 조작**: '화면 조작 모드'를 통해 각 방송 플레이어의 세밀한 제어가 가능합니다.
  - **화면 녹화**: 방송 화면(Canvas 영역)을 고화질/고음질로 녹화할 수 있습니다. (자동 녹화 지원)
- ⌨️ **편리한 단축키**: 자주 사용하는 기능들을 단축키로 빠르게 실행할 수 있습니다.
- 🔄 **실시간 정보 갱신**: 버튼 하나로 모든 채널의 라이브 상태, 시청자 수 등을 새로고침할 수 있습니다.

## 🖥️ 지원 플랫폼

- **치지직 (Chzzk)**
- **숲 (SOOP, 구 아프리카TV)**
- **유튜브 (YouTube)**

## 🚀 시작하기 (Getting Started)

1.  **채널 검색**: 우측 컨트롤러 상단의 검색창에서 원하는 스트리머를 검색하세요.
2.  **채널 추가**: 검색 결과에서 채널을 클릭하여 목록에 추가합니다.
3.  **레이아웃 변경**: 컨트롤러의 레이아웃 버튼을 클릭하거나, 채널 목록의 채널을 화면의 원하는 위치로 드래그하여 배치합니다.
4.  **시작!**: 이제 당신만의 멀티뷰를 즐기세요!

## ⌨️ 단축키 정보 (Shortcuts)

| Key | 기능 |
| :---: | :--- |
| `1`, `2`, `3`... | 레이아웃 유형 변경 |
| `C` | 컨트롤러 펴기/접기 |
| `S` | 설정 열기/닫기 |
| `M` | 라이트/다크 모드 전환 |
| `T` | 현재 시간 표시/숨기기 |
| `V` | 화면 이동/조작 모드 전환 |
| `R` | 모든 채널 정보 새로고침 |
| `F` | 전체 화면 전환 |
| `↑`, `↓` | 화면 비율 변경 |
| `←`, `→` | 채팅창 글자 크기 조절 |

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: Next.js 14 (App Router)
- **Styling**: Material-UI (MUI), Emotion
- **State Management**: Jotai
